How to install

  1. Tap Download APK on your Android phone.
  2. Open the downloaded file. If asked, tap Settings and turn on Allow from this source.
  3. Go back and tap Install.
  4. If Play Protect shows a warning, tap More details, then Install anyway.
  5. Open CINOVA, create an account and start watching.

CINOVA is installed from this website, so it does not update by itself. Check this page for new versions.
